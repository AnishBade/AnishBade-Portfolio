 # Anish Bade — Portfolio

Personal portfolio website for showcasing Anish Bade's work, skills, experience, and contact information.

## Overview

This project is a modern, responsive portfolio application designed to provide a clear introduction, highlight selected projects, and make it easy to get in touch.

## Features

- Responsive layout for desktop, tablet, and mobile devices
- Hero section with personal introduction and calls to action
- About section with background and skills
- Project showcase with links to work and source code
- Contact section for professional inquiries
- Clean, accessible, and easy-to-customize design

## Getting Started

### Prerequisites

- Node.js 18 or later
- npm, pnpm, or yarn

### Installation

```bash
git clone <repository-url>
cd anish-portfolio-app
npm install
```

### Development

Start the local development server:

```bash
npm run dev
```

Open the URL shown in the terminal to view the application.

### Production Build

```bash
npm run build
npm run preview
```

## Customization

Update the portfolio content, project details, links, and contact information in the application source files. Replace images and other static assets in the project's public/assets directory as needed.

## Deployment

Build the application with `npm run build`, then deploy the generated production output using your preferred hosting provider.
